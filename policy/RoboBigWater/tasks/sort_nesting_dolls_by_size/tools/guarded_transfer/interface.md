`robo guarded_transfer <left|right> --x X --y Y --z Z --to_x X --to_y Y --to_z Z --color COLOR`
Transfers between world TCP points in metres with an initially open gripper; preflights observed clearance, complete kinematic path and opposite-hand interference before motion.
`--color surface|yellow|red|green|blue|orange`; `--camera NAME` (head); `--radius M` (.01–.12, default .045) bounds visual verification; `--support_z Z` overrides estimated support, which represents the carried bottom before lift.
`--approach down|down45` (down); `--open x|y` (x); `--clearance M` (.04–.25, default .04); `--payload_radius M` (.01–.15, default .06) bounds carried footprint; `--margin M` (.005–.10, default .025).
`--route auto|direct` (auto) selects observed carry paths and local/merged/constant elevations; auto considers up to seven paths, with at most 28 carry profiles and 168 approach/path checks. Required endpoint clearance above .25 m fails.
Measures baseline before approach; descends, closes, lifts, verifies visual translation, carries, lowers, releases and withdraws vertically above the translated observed top plus max(.02 m, margin), never below final carry elevation; no physical retries.
`robo transfer_clearance --x X --y Y --z Z --to_x X --to_y Y --to_z Z --support_z Z [--camera NAME --payload_radius M --margin M --color COLOR --route auto|direct]` is read-only, costs no action steps and does not check reachability or subtract robot depth; shared option defaults match above, except omitted color includes all depth.
Both return `plan_ok`/`plan_fail_reason`, route, carry waypoints/elevations, support, required clearance, obstacle/destination evidence and limitations; transfer additionally returns preflight/stage diagnostics, lift/release status, `withdraw_z`, `reached_tcp` and `placement_verified=false` on completion.
Invalid arguments, unavailable evidence/calibration, occupied destinations, blocked/unreachable paths or excessive clearance fail; transfer also stops on failed/clipped/inaccurate motion or unverified lift. A failure after closing can leave a payload held; motions consume action steps.
Surface mode includes neutral/dark depth; named hues verify that hue and check bright chromatic obstacles only. Occluded space is unknown; ambiguous support and lift evidence can reject valid motion. Placement stability and full-arm collision freedom are unverified.
Transfer filters modeled active-arm depth with endpoint protections; matching hardware enables detailed hulls and refined hand sweeps, otherwise conservative envelopes/depth remain. Model mismatch can retain robot surfaces or hide contacting scene surfaces; grasp evidence is unfiltered.
